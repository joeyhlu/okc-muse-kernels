## 2. Plumbing (layer → K2A v2.2)

- **Input**: `pre_expert_norm(pooler(ffn_input))`, BF16 [T, 4096], contiguous (16-B pointer check kept from v06).
- **Routing**: the layer's own router (FusedMuseSparkRouting FP32 weights) and r1's device-side local-id table (`lo = 0`): local experts 0..31, remote −1. K2A's route prologue is its only reader of `ids`, and it tests `0 <= id − lo < 32`, so −1 (and any id ≥ 32 when `R1_LOCAL_ID_TABLE = False`) is remote; `meta[MH + p] = −1` is written for remote pairs too. `local_start` is never read on the host.
- **Weights**: the layer's `w13/w13_sf/w13_gs/w2/w2_sf/w2_gs` go in as they are; `post_expert_norm` is passed under v2.2's key `post_norm_w`. v2_prepare binds `bf16(1 + w)` itself, which is SGLang's `post_expert_w`.
- **State**: v2.2's persistent buffers (h 84 MB FP32 kept all-zero between calls, inter, y, meta, bar, err, trace), sized for T ≤ 320. Allocated in prepare. Graph-safe: the pointers are baked into each graph, the experts run on the main stream after the side-stream join, and replays are sequential.
- **Build**: `load_inline` name `k3_k2a_v22_<tag>`, distinct from the moe file's `k2a_v2_<tag>`, so the first box run compiled cold.

## 6. Risks

1. **Grid barriers, no fallback at call time.**
   - v2.2 relies on all CTAs being co-resident: grid = SMs × occupancy, 1–2 grid barriers per call.
   - A barrier timeout (`SPIN_BUDGET` ≈ 34 ms) sets `err` and carries on, which gives silently wrong output; nothing reads `err` on the timed path.
   - In the layer the experts run alone on the main stream after the side-stream join, so co-residency holds as in the moe problem. A concurrent kernel from another stream would break it.
2. **First judge contact for −1 ids.** The ids path is covered by the self-test (−1 convention), all 13 layer tests on the box, and the paired A/B (err 0). The `R1_LOCAL_ID_TABLE = False` convention (ids ≥ 32) is handled by the same comparison but was not run in the layer.
3. **h zero invariant.** h is all-zero between calls only while every call completes. An aborted call (device fault) leaves it dirty, but that is a sticky fault anyway.
4. **Cold nvcc in prepare** is about 44 s on the box. The `K2A_SELF_TEST_START_BY_S = 250` guard still applies, but nvcc itself can't be interrupted.
5. **T=32 route rests on the box A/B** (3.3–4.2% on one shape, a tie on the other). The judge's machine could differ slightly. Either way the T=32 load is within about 2% of v06.
6. **Box vs judge.** The judge clone matched the judge within ~1% on moe. For decode_layer the box's absolute speedups run above the judge's: box k3_v06 1.230 vs judge k3_v04 1.172, a different file. The v07/v06 ratio is the transferable number.
